נתוני מפה

עודכן לאחרונה: 5 October 2026

המפות ב-Collaro, וגינות הכלבים המוצגות בהן, מבוססות על נתונים מ-OpenStreetMap. עמוד זה מסביר מאין מגיעים הנתונים, לפי איזה רישיון הם זמינים, וכיצד Collaro משתמשת בהם.

1. OpenStreetMap ורישיון מסד הנתונים הפתוח

נתוני המפה © תורמי OpenStreetMap. נתוני OpenStreetMap זמינים לפי רישיון מסד הנתונים הפתוח (ODbL) 1.0; דף זכויות היוצרים והרישיון של OpenStreetMap מפרט את תנאיו. תמונות המפה הן © CARTO, ומשורטטות מנתוני OpenStreetMap.

דבר בתנאי השימוש שלנו אינו מגביל את הזכויות ש-ODbL מעניק לכם בנתונים אלה.

2. נתוני גינות הכלבים באפליקציה

גינות הכלבים המוצגות במפה הן הפריטים ב-OpenStreetMap המתויגים leisure=dog_park באזור ש-Collaro משרתת. בערך פעם ביום השרתים שלנו מורידים אותם מ-Overpass API (שירות לשאילתות על נתוני OpenStreetMap) ושומרים עותק, והאפליקציה מציגה את הגינות מתוך העותק הזה. כדי להציג גינות כלבים, האפליקציה אינה פונה ל-OpenStreetMap או ל-Overpass API.

לכל גינה העותק שלנו שומר רק את המזהה שלה ב-OpenStreetMap, את שמה (אם יש לה שם) ונקודה אחת: מיקום הגינה, או, עבור גינה שמופתה כשטח, נקודת המרכז ש-Overpass API מחשב. משמות מוסרים תווי בקרה ורווחים מיותרים, והם מקוצרים ל-120 תווים לכל היותר. דבר אחר אינו משתנה, ולא נוספים נתונים ממקורות אחרים. השאילתה שבה אנו משתמשים: 

[out:json][timeout:60][maxsize:33554432];
nwr["leisure"="dog_park"](29.45,34.2,33.35,35.9);
out tags center qt;

3. קבלת הנתונים

אותם נתונים זמינים ללא תשלום מ-OpenStreetMap — למשל באמצעות הרצת השאילתה שלעיל ב-Overpass API. העותק שלנו של נתוני גינות הכלבים זמין לפי ODbL; כדי לקבל אותו, פנו אלינו בכתובת contact@collaro.app.
